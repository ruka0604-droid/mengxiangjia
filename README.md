### 首次试用

1. 先备份酒馆设置与用户图片目录，更新插件文件并刷新酒馆。
2. 打开梦想家设置，找到「生图连接」。填写接口地址、自己的密钥、服务提供的模型 ID；模型 ID 不能直接用网站显示的中文名称代替。
3. 根据服务要求选择描述格式：较新的结构化格式或基础格式。尺寸、采样器和噪声计划也应以该服务要求为准。
4. 打开一个家，进入「绘制人物、房间与家具」，先核对角色外貌，然后准备人物提示词、绘制一张、检查预览、满意后保存。
5. 人物成功后再绘制空房间背景和家具，避免一次发出大量请求。打开小屋不会自动请求生图。
6. 请求失败时把不含密钥的错误信息反馈即可。保存失败可以保留当前预览重试保存，不必重新出图。

图片由酒馆保存，插件设置只记录路径和生成信息。删除插件文件不等于备份；换设备或迁移酒馆时，需要连同用户图片一起迁移。

## 0.1.0 第一版：盖房子、他回家、小纸条
