# 梦想家

和角色一起住的小家。按角色人设盖一个你们共同的家，一起布置；他会回家、和你互动、回小纸条、写交换日记。每个角色都有自己的家，互不影响。

安装：酒馆「扩展」→「安装扩展」，填 `https://github.com/ruka0604-droid/mengxiangjia`。
进入：魔法棒菜单里的「梦想家」；也可以在梦想家设置里打开可拖动的小屋浮窗。

## 0.9.1 · 配色与美化复查小修

- 修好：美化 CSS 开头如果写了 `@layer xxx;` 这类不带大括号的语句，后面紧跟的那条规则会漏出去改到酒馆页面。现在不会了，导入的美化一定只影响梦想家。
- 修好：`:is(.a, .b)` 这种括号里带逗号的写法，之前会让整条规则失效。
- 修好：`html body .xxx` 这种开头连着写 html 和 body 的，之前永远不生效。
- 导出在手机上更靠得住：下载不了时会复制到剪贴板（http 地址的云酒馆和 TT 也能复制）；连复制也不行时，把导出的内容直接摆在下面，长按全选复制就行。
- 别人发来的导出内容，直接粘贴到「美化 CSS」框里也能用，会自动套上那套配色和美化。
- 美化文件的大小上限统一成 400KB，大的美化不会被截断。

## 0.9.0 · 自己配色、导入美化

- 设置里多了「配色与美化」：
  - 8 套调好的配色可以直接选：燕麦拿铁、雾霾蓝、鼠尾草、藕荷、灰陶、奶油黄，还有两套深色的墨绿夜、夜航蓝。每一套在三种风格的每一页都检查过，字都看得清。
  - 「自己调」：页面底色、顶栏、卡片、文字、次要文字、主色、线条、提醒色，每个都能用取色器随便调，边调边看效果。调得太淡、看不清时会提醒一句，但不拦着。
  - 配色只换颜色，像素风的方块边、手帐的胶带、绘本的圆角这些样子不变。
- 可以「所有的家」共用一套，也可以选「只有某某的家」，让这个角色的家单独用一套配色和美化。
- 导入美化：别人做好的美化（.css 文件，或在这里导出的 .json）可以从文件导入，也可以直接粘贴 CSS，边改边生效。导入的美化只会改梦想家，不会弄乱酒馆。「导出这一套」可以把配色和美化存成一个文件发给别人。
- 想自己做美化的，设置里有「美化接口说明」：能改哪些颜色和字体、每一页的标记、主要部件的名字，还有一份模板可以复制或下载。
- 其他：深色配色下纸条、房间上的提示、新纸条角标这些自带浅色底的地方，字也保持看得清。

## 0.8.2 · 修看不清的字

- 修好：像素风里他回你的那句话，深蓝底配深色字，几乎看不清；布置抽屉里选中的页签也是。现在都换成浅色底。
- 修好：像素风布置页顶上「拖动摆放」那行字看不清。
- 三种风格把每一页的字都检查了一遍，偏淡的说明文字、按钮、选中的选项、你说的话，都调深或调亮到看得清。

## 0.8.1 · 装扮复查小修

- 他每次回家看到小家伙「戴着平安结」，又把同一件报一遍时，不再重复记成「又戴上了平安结」，你给它戴的也不会被改成「他给它戴的」。
- 他写的是「粉色蝴蝶结」「红绳」这种带颜色字的，会按那个颜色画（之前没写色号就用默认色）。
- 他把戴装扮写在日记那一段里时，也能认出来。
- 他在睡觉、打盹、洗澡、做饭、出门时，不会被安排去逗小家伙；平时自己去逗的次数也少了一点。
- 换装扮页的「脖子」「头顶」圆点按起来更大，手机上好拖。

## 0.8.0 · 给小家伙戴装扮，他会来摸摸它

- 他在交换日记、纸条、回家的小场景，或者回应你的时候，如果给小家伙戴上了什么（项圈、铃铛、平安结、领结、小围巾、蝴蝶结、小帽子、小花、小眼镜），就会真的戴在它身上，卡片上写着「他给它戴的」；摘下来也会摘掉。这些都在原来那一次里一起写，不多花接口额度。
- 小家伙卡片上多了「换装扮」：你也可以给它戴、给它摘，挑颜色；脖子、头顶、脸上各戴一件，戴新的会换下同一个位置上的旧的。你给它换了什么，他回家时会看到，可能写纸条说起。
- 照描述画出来的小家伙也能戴：插件会在画好的图上自动找它的脖子和头顶；放得不准时，在换装扮页把「脖子」「头顶」两个圆点拖到对的位置，以后戴什么都按这里放。眼镜只能给模板猫狗戴。
- 「叫他来摸摸它」：他在家时可以叫他过来，他会回一句（花一次接口），然后小人走到它旁边蹲下伸手，它头上冒小爱心，接下来半小时他都在陪它。画好人物立绘的，小家伙会跑到他脚边。
- 平时他在家、没在忙别的时，偶尔也会自己去逗一只小家伙。

## 0.7.1 · 小家伙们复查小修

- 植物长大时那张纸条如果没写成（接口出错或点了取消），成长记录里那一格会出现「请他写一张」，可以补上。
- 植物浇太多后过几天自己缓过来了，下次再蔫时他还会写纸条提醒（之前同一种情况只会提醒一次）。
- 很窄的手机屏幕上，小屋底部的六个入口改成两排，领养页的毛色圆点也不会挤出去。

## 0.7.0 · 小家伙们：养猫养狗、种花种草

- 小屋底部多了一个入口「小家伙们」，分动物和植物两页，最上面是「今天要做的」，点一下就能直接喂、换水、遛、浇水、施肥，做完的会划掉。
- 领养动物有两种方式：
  - 从模板挑：选猫还是狗、挑毛色（猫有橘、白、黑、灰、三花、奶牛，狗有柴、白、黑、棕、奶油、斑点），起名字，选男孩还是女孩，再选先放在哪个房间。不花任何接口额度。
  - 照我说的画：写一句想要什么样的小家伙，插件整理成画面描述再画一张，不满意可以「再画一张」（只花一张图）；再选它的习性像猫（不用遛）还是像狗（每天要遛）。需要先配好生图连接。
- 动物每天喂食、换水，像狗的每天还要遛一次。遛狗可以「我去遛」，也可以「让他去遛」（他在家时才能叫他去）。饿了、渴了、想出门时，房间里它头上会冒个小气泡。
- 动物会自己在各个房间之间溜达，过一会儿就换一间；房间页签上有小点的，说明那间房里有小家伙。在房间里点它，下面会出来照顾它的卡片。也可以把它抱到别的房间。
- 植物可以种仙人球、绿萝、薄荷、向日葵、多肉、小番茄。每天浇水，隔几天施肥，攒够照顾就长到下一个阶段，大约两周长到最后（开花或结果）。每长大一个阶段，他会马上留一张纸条（花一次文字接口）。
- 照顾不好会蔫：连着几天忘了浇水会干蔫，一天浇好几次会浇太多、叶子发黄。照顾回来就好，不会死。
- 点「看成长记录」能看到它从种下到现在每个阶段的样子和日期，他在每个阶段写的纸条贴在那一格下面，还有这一周每天浇了几次水。
- 他回家时会顺便看看小家伙们：他不在家时，猫狗偶尔会捣蛋（咬充电线、叼拖鞋……），植物蔫了、阳台上的淋了雨，他都会写纸条告诉你；平时也可能写一张照顾它们时的小事。这些纸条都在回家那一次里一起写，不额外花接口额度。
- 小纸条页多了「小家伙们」筛选，和它们有关的纸条上会标出是谁、出了什么事。
- 最多养 4 只小动物、4 盆植物。

## 0.6.12 · 他帮忙摆、整间房一起画、生图去背景

- 新功能「让他帮忙摆」：布置时在抽屉最后一页「问问他」（原来的「他挑的」页）里，让他按自己的习惯把这个房间里的东西重新摆一遍——左右位置、靠墙还是靠前、朝向，房间用纯色墙地时还可能顺手换个墙色或地板色，摆完说一句话。整个算一步，不喜欢点撤销就回到原样。每次只调用一次文字接口。
- 修好：改了墙面、地板颜色后显示不出来。原因是这个房间画过背景图，图盖住了颜色。现在选颜色时会自动切到纯色墙和地板，画好的背景还在，想用回来在上面选「用画好的背景」。
- 拉取生图模型：按钮改叫「拉取生图模型 / 看常用模型」。填的是官方地址时，直接在下拉框里列出常用模型的完整 ID，每个后面写着是推荐、最新还是旧版；别的地址拉不到列表时，也会列出这些常用 ID，不用再自己猜全称。从下拉框里选模型时，描述格式会自动配好。
- 画人物和家具后自动去掉纯色背景：四周是一整块纯色时才去，从边缘往里擦、碰到线条就停，边缘的粉边白边也会褪掉，再把四周空白裁掉，放进房间不会出现一个方块、也不会显得小。背景不是纯色、拿不准时保留原图。预览里可以点「用原图」换回去。
- 画家具时画布跟着家具的形状走：书架、衣柜、落地灯这类竖长的用竖图，沙发、床用横图，其他用方图，画出来不会被压扁或留一大片空白。
- 新功能「没画的家具一起画」：绘制页每个房间多了这个按钮。先用一次文字调用整理好所有家具的描述，再一件一件画；画好的都排在上面，满意的单独保存或一起保存，不满意的重画或不要。服务说正忙时会等几秒再试一次；Key、额度、地址这类每件都会失败的错误，会停下来说明原因，不会接着白画。
- 手机上布置抽屉的几个页签能一排放下了。

## 0.6.11 · 减少生图失败，失败时说清楚原因

- 画人物前整理外貌这一步，已经在「他的样子」里确认过外貌的，只把确认的外貌发给文字接口，不再附上整张角色卡和世界书。角色卡里有成人内容时，文字接口常常整条拒绝，生图就一直卡在这一步；现在不会了。还没确认外貌的照旧从角色卡里提取，被拒时会提示先去确认外貌。
- 生图失败时按原因说清楚：Key 不对或失效、额度不够或超出免费范围、地址不对、同一账号同时在画、描述格式选错、连不上服务，各有一句说明和该怎么做，后面再附上服务自己给的原因。
- Key 前面多粘了「Bearer」或带了空格换行，会自动整理掉。
- 新模型选成了「基础描述」时，生图会自动按结构化描述发送，不会再直接报错。
- 「检查填写」能看出更多填错的地方，比如模型 ID 填成了网站上显示的名字。

## 0.6.10 · 生图小修

- 修好：画好一张图还没点「满意，保存」时，关掉梦想家再打开，预览图就没了（那张图已经花了生图额度）。现在会留着，换到别的角色才清掉。
- 人物提示词里，角色外貌挪到画风后面，不再排在最后。提示词很长时，生图服务会把最后的部分截掉，外貌排在最后容易丢，模型也更看重前面的内容。
- 画房间背景和家具时，不再把整张角色卡、世界书和你的人设发给文字接口，只发房子和这件东西本身的信息。省额度，也不会因为角色卡里的成人内容被文字接口拒绝。
- 绘制页的说明改正：人物图片没有动作动画，但在房间里会轻轻晃动。

## 0.6.9 · 可以中途换风格，人物都会动了

- 「房子档案」里可以给已经住进去的家换风格（手帐 / 像素 / 绘本）。画好的图按风格分开保存：换过去以后，那个风格没画过的地方先显示布局草图和那个风格的小人，想要图再到绘制页按新风格画；换回原来的风格，之前那套图原样回来。两种风格的图不会混在一个画面里。换之前会问一次，会说明现在有几张图会收起来、那个风格之前画过几张。换风格本身不花任何接口额度，图片也不删。
- 修好：手帐和绘本风格的小人在部分手机上（尤其 iPhone）不会动。现在三种风格的小人都会轻轻晃。
- 画好的人物立绘也会轻轻呼吸，像素风一格一格地跳；手机开了「减弱动态效果」时不动。

## 0.6.8 · 修世界书读成乱码、外貌被误删

- 修好：0.6.6 起，只要角色有世界书，回家、纸条、日记、盖房子、画人物时读到的世界书全变成了一串「[object Object]」，他其实什么设定都没看到。现在恢复正常，重复的条目也会去掉。
- 只有盖房子、定小人外形、画人物时，讲外貌的世界书条目排在前面；其他生成按世界书原来的顺序读。
- 修好：整理人物外貌时，「及肩黑发」「齐腰银发」这类写法会因为带了「肩」「腰」被当成身体描写删掉；脸上的疤（眉骨、脸颊上的）也被一起删了。现在发型和脸部特征会保留，身高体重、体型、身体上的疤照样不写进立绘。
- 整理后外貌一栏空了时，用你确认过的外貌兜底，人物提示词里不会只剩画风。

## 0.6.7 · 人物立绘改为直接透明背景

- 人物立绘（手帐、乙女、像素三种主题）统一在生图提示词中要求真正的透明背景（alpha 通道），不再请求洋红纯色背景。
- 人物生成结果不再执行洋红色抠图处理，以免意外抠除人物边缘；直接保留服务返回的透明图像。需要注意：是否真有 alpha 通道取决于生图模型及服务能力，纯提示词无法保证透明。
- 「纯色底辅助抠图」开关现在仅用于家具生图，房间背景与家具原有提示词及后处理规则不变。
- 本次不修改角色互动、回家、小纸条、交换日记以及世界书读取分流的业务逻辑；只更新版本缓存标识。

## 0.6.6 · 人物生图风格与角色一致性优化

- 乙女与手帐 Q 版继续各用独立画风：保留圆润脸型及各自精致立绘、柔和贴纸的画法，但不统一改成圆眼、蓬松发型或微笑表情。
- 人物原有眼型、眉形、目光、发型、发色和个性神态优先；寸头不会被风格词强行变成蓬松发型。
- 不再要求乙女主题人物必须成年；未成年人与成年人均保持角色卡设定年龄，不擅自增龄或幼儿化。
- 人物立绘背景要求依照抠图开关二选一：洋红纯色背景（便于去背）或透明背景，不再在同一条提示词里同时指定两者。
- 像素主题的专属画风与专属排除词、房间与家具生图提示词保持原样；通用立绘背景规则同步消除冲突。世界书读取排序、互动、小纸条和交换日记的业务逻辑未改动。

## 0.6.4 · 人物立绘只提取外貌特征

- 盖房子时确认的角色外貌只保留五官、发型、发色、瞳色、肤色、服装和配饰，可保留已明确的性别、年龄；不再提取身高体重、肌肉体型、身体疤痕或私密身体描写。
- 准备人物生图提示词时，只整理这些可见外貌信息，先按固定字段提取，再自动过滤不相关的身体内容，避免角色卡中的成人设定被带进立绘。
- 模型没有正确返回外貌时，不再直接把整段角色描述复制进外貌栏；旧小屋与剧情存档不变。
- 人物立绘明确要求完整着装；房间、家具、小纸条、日记及回家功能不受影响。

## 0.6.2 · 并入另一条开发线（0.5.8–0.5.16）的改进

- 文字接口把「内容审核拒绝」或报错当成回复返回时，不再当成他说的话存进回家记录、纸条和日记，会提示这次没保存。
- 重新提取小人外形时没拿到有效结果，原来的样子保持不变（以前会被重置成默认小人）。
- 纸条接口回的是报错时不当成回信，纸条继续等他回；已经回过的纸条不会再白花一次生成。
- 盖房子、定小人外形、画人物时多读一些角色世界书，讲外貌的条目排在前面；角色描述也读得更完整。模型漏写外貌时，拿角色描述和世界书里讲外貌的几句当草稿，入住前给你确认。
- 画人物时不再在提示词里写「不要胡子、兽耳、尾巴」这类词（反而容易被画出来），只按设定里写明的特征画。
- 生图连接里可以「拉取生图模型」，从下拉框选一个；服务不提供模型列表时照旧手动填。
- 生图出错时，会把服务给的原因一起显示出来，比如模型 ID 不对，一眼就能看出来。
- 三套主题的细节打磨：按钮按下去有反馈、键盘焦点框更清楚、行距和窄屏排版更舒服；像素主题改名「精致像素 · 海盐汽水」。
- 主 API 返回 503 时说明更清楚；副 API 拉取模型时如果返回网页或乱码，会说明原因。

## 0.6.1 · 设置页改成分组折叠，修生图设置填不进

- 设置页不分页了，改成一组一组往下排，顺序和原来一样：小屋浮窗（直接是开关）、文字生成、生成时读取、他什么时候回家、生图连接、更新日志，最下面是拆掉这个家。每组默认收起，收起时下面一行小字写着现在的设置，点一下展开。
- 文字生成里选「跟随当前 API」时，副 API 的设置先藏起来，选「使用副 API」才出现。

## 0.2.0 布置模式：自己摆家具，他会注意到

- 小屋首页多了「布置」入口。进去后直接在房间里拖动家具，会吸附到网格；上下拖可以把落地的家具换到靠墙一排或前排，挂墙的东西可以挂高挂低。
- 点中一件家具后可以左右微调、放前面或后面、翻转、换大小（小、中、大）、换颜色、改名字，或者收进仓库。仓库里的东西随时可以拿回来。
- 每个房间的墙面和地板颜色都能换。
- 抽屉分家具、小物、墙面、灯光、仓库、他挑的。新加了相框、镜子、串灯、鱼缸、衣帽架、坐垫、吉他、一摞书。
- 「描述一件，让 AI 做」：写一句想要什么，AI 把它做成一件家具放进房间。
- 「他挑的」：让他按自己的喜好给这个房间挑几件东西，每件附一句他的话，喜欢就放进去。
- 撤销、重做都在布置页顶上，「完成」一直在顶上不会被滚走。
- 他会注意到你的布置：布置完如果他在家，可以「叫他来看看新布置」；他不在家的话，下次回家时会看到你改了什么。
- 第一次布置某个房间时，会先把现在自动排好的位置定下来，之后完全按你摆的来，不会再自动挪动。

## 0.1.0 第一版：盖房子、他回家、小纸条

- 盖房子：读取角色卡、你的用户人设和角色世界书，由 AI 设计这个家——名字、来历、配色、几个房间、每个房间放什么家具。可以选房子大小（一间小屋、小公寓、带院子），写补充要求，勾选「留些空位，等我们一起布置」。不满意可以换一版，满意了点「就住这里」。
- 小屋首页：画出房间正面图，家具按设计摆好，夜里会暗下来、落地灯会亮；几个房间之间可以切换。他在家时，头像会出现在他待着的那件家具旁边。
- 他回家：打开小屋时，离上次回家够久他就会回来（间隔在设置里调，也可以改成只在你点「等他回家」时回来）。回家会写一个小场景，给你两三件可以做的小事，也可以自己写一句，他会接着回应。
- 点家具：房间里的每件家具都能点，可以叫他过来、在旁边陪他，或者在那儿做点别的。
- 小纸条：分道歉、纪念、日常、想你、谢谢、生气了，可以贴在门边、冰箱、枕边或书桌。可以让他马上回，也可以等他回家时再读；他回家时偶尔也会自己留一张。有新纸条时，房间里和入口上会提示。
- 回家记录：每次回家的场景和你们的来回都留着。
- 生成可以跟随当前 API，也可以用副 API（选酒馆里的连接配置，或手动填写接口）；副 API 走酒馆后端转发，出错时直接告诉你，不会悄悄换成主 API。
- 家存在酒馆的扩展设置里，换设备也在。纸条最多留最近 300 张，回家记录留最近 40 次。
