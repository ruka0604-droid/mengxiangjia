# 梦想家

和角色一起住的小家。按角色人设盖一个你们共同的家，一起布置；他会回家、和你互动、回你的小纸条。每个角色都有自己的家，互不影响。

安装：酒馆「扩展」→「安装扩展」，填 `https://github.com/Zaiyebuzuoyouqingdetiangou/mengxiangjia`。
进入：魔法棒菜单里的「梦想家」；扩展设置里也有「打开梦想家」按钮。

## 0.5.1 魔法棒入口与可选小屋浮窗

- 移除扩展管理页的梦想家自定义设置面板与打开按钮，保留魔法棒菜单中的梦想家入口。所有文字、生图和小屋设置都在梦想家内部。
- 新增小浮窗开关，默认关闭。进入梦想家，点右上角设置，开启「显示可拖动的小屋浮窗」即可使用。
- 浮窗使用透明底暖灯小屋、月亮和星光图片；轻点打开梦想家，拖动调整位置。位置会保存，视口尺寸变化时保持在屏幕范围内。
- 梦想家面板打开时隐藏浮窗，关闭面板后恢复；关闭浮窗开关后仍可从魔法棒进入。
- 禁用插件时会清理浮窗与监听，不留下多余入口。旧版遗留的自定义设置面板也会在初始化时清理。
- 已完成模拟检查：开关、轻点、拖动边界、拖后避免误触、位置保存、视口变化和禁用清理。安卓手机的实际拖动体验仍需试用。

## 0.5.0 独立生图与三套交互主题 · 试用版

- 增加独立生图连接：每位使用者自行填写地址、密钥、模型和绘图参数，不依赖其他扩展；更换地址分别记住密钥和模型。
- 设置里「检查填写」只检查格式，不生图、不验证额度或服务鉴权。到绘制页请求一张图片才能验证实际出图。
- 本版支持兼容图片生成协议的压缩包、直接图片和部分 Base64 返回。第三方服务需要允许浏览器跨域访问；不兼容的请求或返回格式需要另行适配。
- 新增「绘制人物、房间与家具」页面：先用文字接口准备英文提示词，可手动编辑；再请求单张图片，预览满意后保存到酒馆。每次准备或绘制都可能消耗对应服务额度。
- 手帐风使用水彩与铅笔画描述，像素风使用像素美术描述，绘本风使用细腻恋爱绘本插画描述；人物、房间和家具分别绘制。画风和人物一致性仍取决于模型表现，需要预览调整。
- 人物暂为静态图片，搭配心情表情；纯色底辅助抠图只清除与边缘相连的洋红背景，不保证每次都完美，保存前请检查轮廓。
- 已保存的背景和家具显示在布置场景中；家具仍能移动、缩放和翻转。色板不会改变图片颜色，需要重新绘制。
- 三套交互界面分别采用暖纸色手帐、深蓝与暖木色游戏窗、奶油玫瑰色绘本控件；标题、按钮、菜单、日记和家具抽屉沿用选定主题。
- 暂不增加自定义图片上传或默认美术素材。新家在生成图片前显示布局草图；旧家保留原有数据和程序绘图，不需要删除。
- 已验证语法、接口参数、图片解码、模拟预览保存和存档保护。真实第三方接口、安卓酒馆及不同版本兼容性尚未实测；本版请先作为试用版使用。

### 首次试用

1. 先备份酒馆设置与用户图片目录，更新插件文件并刷新酒馆。
2. 打开梦想家设置，找到「生图连接」。填写接口地址、自己的密钥、服务提供的模型 ID；模型 ID 不能直接用网站显示的中文名称代替。
3. 根据服务要求选择描述格式：较新的结构化格式或基础格式。尺寸、采样器和噪声计划也应以该服务要求为准。
4. 打开一个家，进入「绘制人物、房间与家具」，先核对角色外貌，然后准备人物提示词、绘制一张、检查预览、满意后保存。
5. 人物成功后再绘制空房间背景和家具，避免一次发出大量请求。打开小屋不会自动请求生图。
6. 请求失败时把不含密钥的错误信息反馈即可。保存失败可以保留当前预览重试保存，不必重新出图。

图片由酒馆保存，插件设置只记录路径和生成信息。删除插件文件不等于备份；换设备或迁移酒馆时，需要连同用户图片一起迁移。

## 0.4.0 三种小屋风格 · 基础框架

- 建家时可选温暖复古手帐、精致像素、乙女游戏绘本；每个角色独立保存，入住后不提供切换。重新设计房屋也保留原风格。
- 入住前可核对和手动修改 AI 提取的外貌描述、发型、配饰和基础颜色。入住后也能编辑外貌、按确认描述重新生成小人。
- 人物随主题使用像素或基础矢量 Q 版表现，回家时根据心情显示 emoji 或颜文字。
- 旧存档继续使用原来的像素风，纸条、日记和回家记录保留。
- 这是先跑通流程的版本。AI 目前生成的是结构化外貌与家具数据，由插件绘图；尚未接入图片生成，不会自动产出精细手绘立绘。三种主题共用现有家具绘图，专属家具美术和精细动作后续完善。
- 安装前备份酒馆数据。将压缩包里的运行文件放进现有梦想家扩展目录，保留原路径；完成后刷新酒馆。压缩包不能作为插件安装网址，网址安装仍需先把文件上传到仓库。
- 已做语法和模拟流程检查；真实安卓酒馆与 TT 设备兼容性仍需实际试用。

## 0.3.0 Q 版像素小人、交换日记

- 他在家时，房间里出现的是他的 Q 版像素小人，不再是头像。小人的发型、发色、瞳色、肤色、衣服和配饰（眼镜、帽子、围巾、耳钉）按人设来定：新盖的房子在设计时一起定好；以前盖的房子先用一个默认样子，可以点「按人设重新生成」。
- 小人的姿势跟着他在做的事变：坐在沙发、椅子、床上时是坐着的；看书时手里拿着书，喝茶喝咖啡时拿着杯子；睡着或打盹时闭着眼，头上冒「z」。
- 点房间里的小人，或者在「房子档案」里点「他的样子」，可以自己改发型、配饰和颜色。
- 新增「交换日记」：横线本，你写一篇、他写一篇。可以选天气、引用一段聊天。写完点「合上本子，放回书桌」。
- 他什么时候接着写可以选：他回家时（和回家那次一起写，不多花一次调用）、每天一次（打开本子时，他今天还没写就会写）、我叫他写。不管选哪种，轮到他时都可以点「叫他现在写」。
- 他写了新日记，首页「交换日记」入口会有提示。

## 0.2.0 布置模式：自己摆家具，他会注意到

- 小屋首页多了「布置」入口。进去后直接在房间里拖动家具，会吸附到网格；上下拖可以把落地的家具换到靠墙一排或前排，挂墙的东西可以挂高挂低。
- 点中一件家具后可以左右微调、放前面或后面、翻转、换大小（小、中、大）、换颜色、改名字，或者收进仓库。仓库里的东西随时可以拿回来。
- 每个房间的墙面和地板颜色都能换。
- 抽屉分家具、小物、墙面、灯光、仓库、他挑的。新加了相框、镜子、串灯、鱼缸、衣帽架、坐垫、吉他、一摞书。
- 「描述一件，让 AI 做」：写一句想要什么，AI 把它做成一件家具放进房间。
- 「他挑的」：让他按自己的喜好给这个房间挑几件东西，每件附一句他的话，喜欢就放进去。
- 撤销、重做都在布置页顶上，「完成」一直在顶上不会被滚走。
- 他会注意到你的布置：布置完如果他在家，可以「叫他来看看新布置」；他不在家的话，下次回家时会看到你改了什么。
- 第一次布置某个房间时，会先把现在自动排好的位置定下来，之后完全按你摆的来，不会再自动挪动。

## 0.1.0 第一版：盖房子、他回家、小纸条

- 盖房子：读取角色卡、你的用户人设和角色世界书，由 AI 设计这个家——名字、来历、配色、几个房间、每个房间放什么家具。可以选房子大小（一间小屋、小公寓、带院子），写补充要求，勾选「留些空位，等我们一起布置」。不满意可以换一版，满意了点「就住这里」。
- 小屋首页：画出房间正面图，家具按设计摆好，夜里会暗下来、落地灯会亮；几个房间之间可以切换。他在家时，头像会出现在他待着的那件家具旁边。
- 他回家：打开小屋时，离上次回家够久他就会回来（间隔在设置里调，也可以改成只在你点「等他回家」时回来）。回家会写一个小场景，给你两三件可以做的小事，也可以自己写一句，他会接着回应。
- 点家具：房间里的每件家具都能点，可以叫他过来、在旁边陪他，或者在那儿做点别的。
- 小纸条：分道歉、纪念、日常、想你、谢谢、生气了，可以贴在门边、冰箱、枕边或书桌。可以让他马上回，也可以等他回家时再读；他回家时偶尔也会自己留一张。有新纸条时，房间里和入口上会提示。
- 回家记录：每次回家的场景和你们的来回都留着。
- 生成可以跟随当前 API，也可以用副 API（选酒馆里的连接配置，或手动填写接口）；副 API 走酒馆后端转发，出错时直接告诉你，不会悄悄换成主 API。
- 家存在酒馆的扩展设置里，换设备也在。纸条最多留最近 300 张，回家记录留最近 40 次。
